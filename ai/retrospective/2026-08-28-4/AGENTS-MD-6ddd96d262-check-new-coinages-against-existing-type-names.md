# agent instruction

**Check new coinages against existing type names.** "Before introducing a new term in a prompt, plan, or document, check it against the names of existing artifact types and settled vocabulary. If the term collides with or shadows one, rename yours before it ships."

*Grounded in: "type-notes-last" colliding with the note artifact type.*

# justification

Minutes after Jonathan defined the note artifact type, the phrase "type-notes-last" appeared in the kickstart draft meaning something entirely different (per-type agent-facing descriptions). Jonathan had to ask "What do you mean about type-notes-last? Please explain further" - a full clarification round plus a rename to "type descriptions" in a ratified document. The marginal cost of the rule is a ten-second scan of type names before shipping a term; the cost of skipping it was user confusion inside the single most important document of the session.
