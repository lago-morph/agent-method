# ai/

AI-generated working documents: plans, checklists, status reports,
handoffs - anything an AI partner produces to run or track its own work.

Kept separate so working residue never mixes with the method definition
(`method/`) or with real artifacts (`workbench/`).

`procedures/` holds execution methods the AI partner has recorded by
retrospecting on what it actually did for an implementation. They are
working documents, non-normative, revised as later implementations
repeat the work, and the starting point for formalizing the method's
support materials later.
