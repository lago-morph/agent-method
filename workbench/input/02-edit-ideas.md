# Edit ideas

*Source: PDF page 7, dated 2026-08-16.*

- Text editor with copy/cut/paste shortcuts.
- Idea list is updated as idea is edited.
- Long text undo — if undo a split, restores text, but does not delete the
  split idea.
- Text edit redo.
- Undo buffer cleared when another idea is selected, or click new idea, or
  tab/browser closed.
- If idea has no text when clicking another idea or the new button, the
  idea is deleted even if there are tags defined.
