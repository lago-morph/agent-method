# Label ideas

*Source: PDF page 10, dated 2026-08-16.*

- Label ideas — "." separating hierarchy — e.g., `x.y.z`.
- Labels have no leading/trailing spaces. All printable UTF-8 characters
  are OK; space is the only whitespace allowed. Period reserved for
  hierarchy.
- Item can be in multiple labels. Same idea could be tagged `x`, `x.y`,
  `x.b`, etc.
- Populate left pane with list of labels in alphabetical order.
- Labels are binary: either 0 or 1 instance per idea. Cannot add the same
  label twice.
- Label display updated as labels are added, or when all tags with a given
  value are deleted.
- Add to idea editor: box with labels; can click "x" on a label to delete.
  Type a new label to create.
