# Import ideas

*Source: PDF page 15, dated 2026-08-16. Covers the "import text files" use
case; URL/GitHub imports from the master list have no detail page yet.*

- Paste text after clicking on "new" button.
- Import button — place to drag/drop multiple files (text only to start).
- Import also supports pasting files.
- Import allows clicking "Browse…" button to select files.
- File import — first line of new idea is the filename with ".txt" removed
  if present.
- Each idea has a unique GUID — not a problem to import multiple files from
  different paths with the same filename.
- No label on import.
- On import, removes whitespace at beginning of file.
