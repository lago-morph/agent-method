# Save ideas

*Source: PDF page 8, dated 2026-08-16. Covers both "save ideas (manual)"
and "save ideas (auto)" from the use case list.*

- Everything saved in memory.
- Memory synced to durable storage every 30 seconds or when save button is
  clicked.
- Save button visually indicates if synced.
- Closing tab or browser auto-syncs before closing.
