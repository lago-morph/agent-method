# Save/restore UI state

*Source: PDF page 9, dated 2026-08-16.*

- Currently selected idea is stored at the same time data is saved.
- When opened again, restores UI state, including as new UI elements are
  added.
- Initially the state restored is the selected idea.

*Other pages add to the saved UI state: label filter selection
([07](07-filter-ideas.md)), label collapsed/expanded state
([09](09-hierarchical-display-labels.md)), and the "show details" toggle
([11](11-ui-enhancements.md)).*
