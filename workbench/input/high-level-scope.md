## Idea Workbench (2026-07-29)

- Capture + manipulate ideas (incl. URLs).
- Ideas grow from seed to implementation.

  Sketch: Idea → Spec → System; Spec also feeds Docs and Tests, and both
  Docs and Tests validate the System.

- Can be guided or manual (workflow).
- Integrates all projects somehow.
- Idea N:N with specs.
- Changing/elaborating idea flows to specs. Same with specs →
  implementation. Manual trigger; indicator that sync is needed.
- Ideas, specs, implementation can be combined and split (with guidance).
- Can grow ideas over time. Combine and split, copy/paste for ideas +
  patterns.
- Guided interviews, 1 question at a time.
- Can capture agent ideas in one session and make them persistent.
- Miro/Notion interface to manipulate ideas. 2-way. Post-its + arrows +
  comments.
- Capture ideas from iPhone notes, GitHub issues, voice memos, reMarkable
  handwritten.
- Capture bookmarks/URLs as part of process.
- Interactive sorting/organizing ideas, grouping together. Linked to
  implementation.
- Take work done on existing projects, especially ideas + intent, and be
  able to explain to others, or grab ideas + reuse/refactor.
- If URL is part of idea, can right-click on link to put AI-generated
  summary as text after next line break after idea. Ctrl-Z undoes insert.
