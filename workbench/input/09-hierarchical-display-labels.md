# Hierarchical display — labels

*Source: PDF page 14, dated 2026-08-16.*

- Labels displayed like a file browser with folders.
- Can be collapsed/expanded.
- If clicked on while collapsed, all child items are either selected or
  deselected.
- If a mixed-selection hierarchy is collapsed, shows as a third style
  (partially-selected).
- Clicking a partially-selected collapsed item selects all.
- "Root" folder allows collapsing/expanding all.
- When a hierarchy of mixed collapsed/expanded folders is collapsed then
  expanded, the previous mix of collapsed/expanded is preserved.
- Can right-click on an item and choose "collapse all" or "expand all".
- Label collapsed/expanded state is saved with UI state and restored on
  startup.
