# method/

Everything about the method itself, independent of any particular
application: artifact type descriptions and schemas (in `types/`), link
conventions (`CONVENTIONS.md`), agent-facing background on each type's
intent and how instances may evolve, eventually linters and other
tooling. Adopted architecture decision records for the method live in
`adr/`. The plan for how the method progresses lives in `ai/PLAN.md`.

Nothing in this directory is an artifact of a system being specified; those
live in `workbench/`. AI working documents live in `ai/`.
