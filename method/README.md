# method/

Everything about the method itself, independent of any particular
application: artifact type descriptions and schemas, link conventions,
agent-facing background on each type's intent and how instances may evolve,
eventually linters and other tooling - plus design documents about how we
want the method to progress (starting with `SEED.md`).

Nothing in this directory is an artifact of a system being specified; those
live in `workbench/`. AI working documents live in `ai/`.
