# Archive — the first attempt (June 2026)

Everything in this directory is the first-attempt methodology design and its
harvested content, kept for reference. It is not process: nothing active
depends on it, and new work must not depend on it without a conversation
first. Pieces get re-derived into the live method on merit — several already
have (typed edges → relationships, reconciler → status evaluation,
mechanical/judge/human gate items → per-item evaluation methods).
