# agent-method

A software-development methodology for one human plus AI agent partners,
being rebuilt requirements-first after a too-complex first attempt.
**Not a dark factory:** attended, interactive operation.

- `GLOSSARY.md` - the working vocabulary (start here)
- `REQUIREMENTS.md` - candidate requirements register, with sources
- `LESSONS.md` - incident-cited lessons; the reason things are shaped this way
- `reviews/` - dated records of analyses and the decisions behind them
- `archive/` - the first attempt, kept for reference; not process

Status (July 2026): vocabulary and candidate requirements under joint
markup; pilot project selection pending.
