# agent-method

A method for growing an idea into a specified system: typed artifacts
linked in a graph, developed in cooperation with an AI partner. Restarted
clean on 2026-08-28; the current starting point is
[`method/SEED.md`](method/SEED.md).

## Where to look

| Directory | What's there |
|---|---|
| [`method/`](method/) | The method itself: artifact types, link conventions, schemas, and design documents about how the method progresses. Start with `SEED.md`. |
| [`workbench/`](workbench/) | Artifacts of **idea-workbench**, the first application being specified with the method. |
| [`ai/`](ai/) | Working documents produced by the AI partner: plans, drafts, checklists, handoffs. |
| [`archive/`](archive/) | First attempt at the methodology. Aborted; kept for reference only. |
| [`archive-2/`](archive-2/) | Second attempt, a requirements-first rebuild. Aborted; kept for reference only. |

`CLAUDE.md` is guidance for AI agents working in this repository.
